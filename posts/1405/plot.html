راهنمای جامع رسم دیجیتالی نمودار توابع ریاضی

سلام به همهٔ علاقه‌مندان ریاضی و برنامه‌نویسی! امروز می‌خواهیم با هم دنیای جذاب رسم نمودار توابع ریاضی را کشف کنیم. از توابع سادهٔ دو بعدی مثل y = sin(x) بگیرید تا سطوح پیچیدهٔ سه‌بعدی مثل z = cos(x² + y²). قرار است هم ابزارهای آماده و رایگان را معرفی کنم، هم برویم سراغ کدنویسی با WebGL. پس کمربندها را ببندید!

1. رسم نمودارهای دوبعدی

1.1. سایت Desmos (غول قدرتمند و رایگان)

آدرس: desmos.com/calculator

دسموس محبوب‌ترین ماشین‌حساب گرافیکی آنلاین است. کار باهاش بی‌نهایت ساده است:

  • عبارت تابع را در کادر سمت چپ تایپ کنید، مثلاً: y = sin(x)
  • برای توابع چندجمله‌ای: y = x^3 - 4x^2 + 5
  • می‌توانید با کلیک روی دکمهٔ "+" چندین تابع را همزمان رسم کنید.
  • برای رسم توابع پارامتری، از حالت Parametric استفاده کنید.

مثال: تابع y = x^3 - 3x را در Desmos رسم کنید و ببینید چطور نقاط بحرانی (ماکزیمم و مینیمم) را نشان می‌دهد. دسموس به‌طور خودکار نقاط تقاطع، ماکزیمم، مینیمم و نقاط عطف را تشخیص می‌دهد و با کلیک روی آن‌ها مختصات دقیق را نشان می‌دهد.

1.2. سایت GeoGebra (قهرمان چندمنظوره)

آدرس: geogebra.org/graphing

جئوجبرا فقط یک رسم‌کنندهٔ نمودار نیست، یک آزمایشگاه کامل ریاضی است:

  • در نوار ورودی سمت چپ بنویسید: f(x) = e^x
  • می‌توانید نقطه بگذارید، خط مماس رسم کنید، و حتی انتگرال‌ها را به صورت بصری نمایش دهید.
  • قابلیت اسلایدر دارد. مثلاً بنویسید: y = a*sin(b*x). خودش دو اسلایدر برای a و b می‌سازد تا با حرکت دادنشان تأثیرشان را ببینید.

مثال عملی: تابع f(x) = x² را رسم کنید. سپس با ابزار "Tangents" روی یک نقطه از نمودار کلیک کنید. جئوجبرا معادلهٔ خط مماس را هم نمایش می‌دهد!

1.3. WolframAlpha (دستیار هوشمند)

آدرس: wolframalpha.com

ولفرام آلفا مثل یک موتور جستجوی ریاضی کار می‌کند. کافی است تابع را به زبان طبیعی یا ریاضی تایپ کنید:

  • بنویسید: plot sin(x), cos(x) from x=-2pi to 2pi
  • یا: plot x^3 - 4x^2 + 5x - 2
  • می‌توانید چند تابع را با کاما جدا کنید و همزمان ببینید.

ولفرام آلفا علاوه بر نمودار، اطلاعات تحلیلی مثل ریشه‌ها، دامنه، برد، و نقاط بحرانی را هم نشان می‌دهد. عالی برای بررسی تکالیف!

1.4. نرم‌افزارهای دسکتاپ

  • Gnuplot (رایگان و متن‌باز): قدرتمند و مبتنی بر خط فرمان. عالی برای رسم داده‌های علمی. دستور ساده: plot sin(x)
  • MATLAB / Octave: ابزار حرفه‌ای برای محاسبات عددی. رسم نمودار در متلب با fplot(@sin) انجام می‌شود. Octave نسخهٔ رایگان و سازگار با متلب است.
  • Maple قدرتمند و مبتنی بر خط فرمان. یک نرم‌افزار همه کاره برای محاسبات عددی و انتزاعی. عالی برای رسم داده‌های علمی. هرچند این نرم‌افزار رایگان نیست، اما ارزش استفاده را دارد. علاوه بر قابلیت‌های بی‌شمار، یک راهنمای قوی (Help) دارد که با مثالهای فراوان روش استفاده از نرم‌افزار را آموزش داده است. دستور ساده برای رسم نمودار: plot(sin(x))
  • Mathematica این نرم‌افزار شبیه به نرم‌افزار میپل است یعنی قدرتمند و مبتنی بر خط فرمان. یک نرم‌افزار همه کاره برای محاسبات عددی و انتزاعی. عالی برای رسم داده‌های علمی. هرچند این نرم‌افزار رایگان نیست، اما ارزش استفاده را دارد. علاوه بر قابلیت‌های بی‌شمار، یک راهنمای قوی (Help) دارد که با مثالهای فراوان روش استفاده از نرم‌افزار را آموزش داده است. دستور ساده برای رسم نمودار: Plot[Sin[x], {x, 0, 10}]

2. رسم نمودارهای دوبعدی در وب با Canvas (فایل HTML کامل)

حالا می‌رسیم به بخش کدنویسی. می‌خواهیم یک فایل HTML کامل بسازیم که بتواند توابع ریاضی دوبعدی را رسم کند. از Canvas استفاده می‌کنیم که در تمام مرورگرهای مدرن پشتیبانی می‌شود و نیازی به کتابخانهٔ خارجی ندارد.

فایل زیر را با پسوند html. ذخیره کنید و در مرورگر باز کنید. می‌توانید تابع را تغییر دهید، زوم کنید، و با ماوس جابجا شوید. همه چیز در همین یک فایل است.

  <script>
    (function() {
      const canvas = document.getElementById('graphCanvas');
      const ctx = canvas.getContext('2d');
      const functionInput = document.getElementById('functionInput');
      const xMinInput = document.getElementById('xMinInput');
      const xMaxInput = document.getElementById('xMaxInput');
      const yMinInput = document.getElementById('yMinInput');
      const yMaxInput = document.getElementById('yMaxInput');
      const precisionInput = document.getElementById('precisionInput');
      const drawButton = document.getElementById('drawButton');
      const resetButton = document.getElementById('resetButton');
      const valueDisplay = document.getElementById('valueDisplay');
      const exampleChips = document.querySelectorAll('.example-chip');

      let xMin = -8, xMax = 8, yMin = -5, yMax = 5;
      let isDragging = false, dragStartX = 0, dragStartY = 0;
      let dragStartXMin = 0, dragStartXMax = 0, dragStartYMin = 0, dragStartYMax = 0;
      let mouseX = null, mouseY = null;

      function readBoundsFromInputs() {
        xMin = parseFloat(xMinInput.value);
        xMax = parseFloat(xMaxInput.value);
        yMin = parseFloat(yMinInput.value);
        yMax = parseFloat(yMaxInput.value);
        if (isNaN(xMin) || isNaN(xMax) || isNaN(yMin) || isNaN(yMax)) return false;
        if (xMin >= xMax || yMin >= yMax) {
          alert('بازه نامعتبر است. مطمئن شوید xMin < xMax و yMin < yMax.');
          return false;
        }
        return true;
      }

      function readPrecision() {
        const precision = parseInt(precisionInput.value);
        if (isNaN(precision) || precision < 2) {
          alert('دقت باید حداقل ۲ نقطه باشد.');
          return null;
        }
        if (precision > 100000) {
          alert('دقت بیش از ۱۰۰٬۰۰۰ نقطه ممکن است مرورگر را کند کند.');
          return null;
        }
        return precision;
      }

      function updateInputsFromBounds() {
        xMinInput.value = xMin;
        xMaxInput.value = xMax;
        yMinInput.value = yMin;
        yMaxInput.value = yMax;
      }

      function toCanvasX(mathX) { return ((mathX - xMin) / (xMax - xMin)) * canvas.width; }
      function toCanvasY(mathY) { return canvas.height - ((mathY - yMin) / (yMax - yMin)) * canvas.height; }
      function toMathX(canvasX) { return xMin + (canvasX / canvas.width) * (xMax - xMin); }
      function toMathY(canvasY) { return yMin + ((canvas.height - canvasY) / canvas.height) * (yMax - yMin); }

      function niceStep(range) {
        const roughStep = range / 10;
        const magnitude = Math.pow(10, Math.floor(Math.log10(roughStep)));
        const residual = roughStep / magnitude;
        let niceResidual;
        if (residual <= 1.5) niceResidual = 1;
        else if (residual <= 3.5) niceResidual = 2;
        else if (residual <= 7.5) niceResidual = 5;
        else niceResidual = 10;
        return niceResidual * magnitude;
      }

      function drawGrid() {
        ctx.clearRect(0, 0, canvas.width, canvas.height);
        ctx.fillStyle = '#0a0a1a';
        ctx.fillRect(0, 0, canvas.width, canvas.height);

        const xRange = xMax - xMin;
        const yRange = yMax - yMin;
        const xStep = niceStep(xRange);
        const yStep = niceStep(yRange);

        ctx.strokeStyle = 'rgba(255, 255, 255, 0.06)';
        ctx.lineWidth = 1;
        let xStart = Math.ceil(xMin / xStep) * xStep;
        for (let x = xStart; x <= xMax; x += xStep) {
          const cx = toCanvasX(x);
          ctx.beginPath(); ctx.moveTo(cx, 0); ctx.lineTo(cx, canvas.height); ctx.stroke();
        }
        let yStart = Math.ceil(yMin / yStep) * yStep;
        for (let y = yStart; y <= yMax; y += yStep) {
          const cy = toCanvasY(y);
          ctx.beginPath(); ctx.moveTo(0, cy); ctx.lineTo(canvas.width, cy); ctx.stroke();
        }

        ctx.strokeStyle = 'rgba(255, 255, 255, 0.5)';
        ctx.lineWidth = 1.5;
        if (yMin <= 0 && yMax >= 0) {
          const cy = toCanvasY(0);
          ctx.beginPath(); ctx.moveTo(0, cy); ctx.lineTo(canvas.width, cy); ctx.stroke();
        }
        if (xMin <= 0 && xMax >= 0) {
          const cx = toCanvasX(0);
          ctx.beginPath(); ctx.moveTo(cx, 0); ctx.lineTo(cx, canvas.height); ctx.stroke();
        }

        ctx.fillStyle = 'rgba(255, 255, 255, 0.7)';
        ctx.font = '12px "Segoe UI", Tahoma, sans-serif';
        ctx.textAlign = 'center';
        ctx.textBaseline = 'top';
        for (let x = xStart; x <= xMax; x += xStep) {
          if (Math.abs(x) < xStep / 100) continue;
          const cx = toCanvasX(x);
          const cy = toCanvasY(0);
          ctx.fillText(parseFloat(x.toFixed(4)), cx, cy + 6);
        }
        ctx.textAlign = 'right';
        ctx.textBaseline = 'middle';
        for (let y = yStart; y <= yMax; y += yStep) {
          if (Math.abs(y) < yStep / 100) continue;
          const cx = toCanvasX(0);
          const cy = toCanvasY(y);
          ctx.fillText(parseFloat(y.toFixed(4)), cx - 8, cy);
        }
        if (xMin <= 0 && xMax >= 0 && yMin <= 0 && yMax >= 0) {
          ctx.fillStyle = 'rgba(255, 255, 255, 0.9)';
          ctx.textAlign = 'right';
          ctx.textBaseline = 'top';
          ctx.fillText('0', toCanvasX(0) - 6, toCanvasY(0) + 4);
        }
      }

      function evaluateFunction(funcStr, x) {
        try {
          const f = new Function('x', `return ${funcStr};`);
          const result = f(x);
          if (typeof result !== 'number' || !isFinite(result)) return NaN;
          return result;
        } catch (e) { return NaN; }
      }

      function drawFunction() {
        const funcStr = functionInput.value.trim();
        if (!funcStr) return;

        const precision = readPrecision();
        if (precision === null) return;

        ctx.beginPath();
        ctx.strokeStyle = '#ff6b6b';
        ctx.lineWidth = 2.5;
        ctx.lineJoin = 'round';
        ctx.lineCap = 'round';
        ctx.shadowColor = 'rgba(255, 107, 107, 0.6)';
        ctx.shadowBlur = 8;

        let firstPoint = true;
        let prevY = null;
        const step = (xMax - xMin) / precision;

        for (let i = 0; i <= precision; i++) {
          const x = xMin + i * step;
          const px = toCanvasX(x);
          const y = evaluateFunction(funcStr, x);

          if (isNaN(y)) { firstPoint = true; prevY = null; continue; }

          const cy = toCanvasY(y);
          if (prevY !== null && Math.abs(y - prevY) > (yMax - yMin) * 0.8) {
            firstPoint = true;
          }

          const clampedCy = Math.max(-1000, Math.min(2000, cy));
          if (firstPoint) { ctx.moveTo(px, clampedCy); firstPoint = false; }
          else { ctx.lineTo(px, clampedCy); }

          prevY = y;
        }

        ctx.stroke();
        ctx.shadowColor = 'transparent';
        ctx.shadowBlur = 0;
      }

      function drawCrosshair() {
        if (mouseX === null || mouseY === null) return;
        if (mouseX < 0 || mouseX > canvas.width || mouseY < 0 || mouseY > canvas.height) return;
        const mathX = toMathX(mouseX);
        const mathY = toMathY(mouseY);
        ctx.save();
        ctx.setLineDash([4, 6]);
        ctx.strokeStyle = 'rgba(255, 255, 255, 0.35)';
        ctx.lineWidth = 1;
        ctx.beginPath(); ctx.moveTo(mouseX, 0); ctx.lineTo(mouseX, canvas.height); ctx.stroke();
        ctx.beginPath(); ctx.moveTo(0, mouseY); ctx.lineTo(canvas.width, mouseY); ctx.stroke();
        ctx.restore();
        ctx.beginPath();
        ctx.arc(mouseX, mouseY, 5, 0, Math.PI * 2);
        ctx.fillStyle = 'rgba(255, 107, 107, 0.7)';
        ctx.fill();
        ctx.strokeStyle = 'white';
        ctx.lineWidth = 1.5;
        ctx.stroke();

        const funcStr = functionInput.value.trim();
        let funcValue = '—';
        if (funcStr) {
          const val = evaluateFunction(funcStr, mathX);
          if (!isNaN(val)) funcValue = val.toFixed(6);
        }
        valueDisplay.innerHTML = `📍 x = ${mathX.toFixed(4)} | y = ${mathY.toFixed(4)} | f(x) = ${funcValue}`;
      }

      function render() {
        drawGrid();
        drawFunction();
        drawCrosshair();
      }

      canvas.addEventListener('mousedown', (e) => {
        isDragging = true;
        dragStartX = e.offsetX;
        dragStartY = e.offsetY;
        dragStartXMin = xMin; dragStartXMax = xMax;
        dragStartYMin = yMin; dragStartYMax = yMax;
        canvas.style.cursor = 'grabbing';
      });
      window.addEventListener('mouseup', () => { isDragging = false; canvas.style.cursor = 'grab'; });
      window.addEventListener('mousemove', (e) => {
        const rect = canvas.getBoundingClientRect();
        const canvasX = e.clientX - rect.left;
        const canvasY = e.clientY - rect.top;
        if (isDragging) {
          const dx = canvasX - dragStartX;
          const dy = canvasY - dragStartY;
          const xRange = dragStartXMax - dragStartXMin;
          const yRange = dragStartYMax - dragStartYMin;
          const dxMath = -(dx / canvas.width) * xRange;
          const dyMath = (dy / canvas.height) * yRange;
          xMin = dragStartXMin + dxMath;
          xMax = dragStartXMax + dxMath;
          yMin = dragStartYMin + dyMath;
          yMax = dragStartYMax + dyMath;
          updateInputsFromBounds();
          render();
        } else {
          mouseX = canvasX; mouseY = canvasY;
          render();
        }
      });

      canvas.addEventListener('wheel', (e) => {
        e.preventDefault();
        const rect = canvas.getBoundingClientRect();
        const mouseCanvasX = e.clientX - rect.left;
        const mouseCanvasY = e.clientY - rect.top;
        const mathX = toMathX(mouseCanvasX);
        const mathY = toMathY(mouseCanvasY);
        const zoomFactor = e.deltaY > 0 ? 1.15 : 1 / 1.15;
        const newXMin = mathX - (mathX - xMin) * zoomFactor;
        const newXMax = mathX + (xMax - mathX) * zoomFactor;
        const newYMin = mathY - (mathY - yMin) * zoomFactor;
        const newYMax = mathY + (yMax - mathY) * zoomFactor;
        const newXRange = newXMax - newXMin;
        const newYRange = newYMax - newYMin;

  • بنویسید: z = sin(x) * cos(y)
  • با ماوس می‌توانید نمودار را بچرخانید و از زوایای مختلف ببینید.
  • رنگ‌بندی بر اساس ارتفاع (ارتفاع z) انجام می‌شود که به درک بهتر سطح کمک می‌کند.

محیط سه‌بعدی جئوجبرا بی‌نظیر است:

  • در نوار ورودی بنویسید: f(x,y) = x^2 - y^2 (سطح زین‌اسبی یا سهمی‌گون هذلولی)
  • می‌توانید سطوح را با صفحه‌ها ببرید (Cross Section).
  • امکان تعریف توابع پارامتری برای رسم خم‌های فضایی هم وجود دارد: Curve(cos(t), sin(t), t, t, 0, 10)

4. رسم نمودار با گوگل

شاید ندانید، اما خود موتور جستجوی گوگل هم می‌تواند نمودار رسم کند! کافی است تابع را مستقیماً در نوار جستجو تایپ کنید. لازم به ذکر است بعضی مواقع قابلیت رسم نمودار در گوگل کار می‌کند، بعضی مواقع کار نمی‌کند. در هر حالت علاوه بر نمودار، گوگل تعدادی سایت مرتبط با رسم نمودار ارائه می‌دهد که می‌تواند برای رسم نمودار مفید باشد.

4.1. رسم توابع دوبعدی

  • در گوگل جستجو کنید: y = x^3 - 3x یا sin(x)
  • گوگل یک نمودار تعاملی در بالای نتایج نشان می‌دهد.
  • می‌توانید با ماوس روی نمودار زوم کنید و جابجا شوید.
  • برای دیدن جزئیات، روی نمودار کلیک کنید. وارد صفحهٔ ماشین‌حساب گرافیکی گوگل می‌شوید.

4.2. رسم توابع سه‌بعدی

  • در گوگل جستجو کنید: z = x^2 + y^2
  • گوگل یک سطح سه‌بعدی زیبا نمایش می‌دهد که می‌توانید آن را بچرخانید.
  • مثال جذاب: z = sin(x) + cos(y)
  • مثال پیچیده‌تر: z = e^(-(x^2 + y^2)) (سطح گاوسی)

این قابلیت گوگل واقعاً برای بررسی سریع یک تابع عالی است. نیازی به هیچ سایت یا نرم‌افزار اضافه‌ای ندارید.

    // ========== Helper: Nice Step ==========
    function niceStep(range, targetTicks) {
      const roughStep = range / targetTicks;
      const magnitude = Math.pow(10, Math.floor(Math.log10(roughStep)));
      const residual = roughStep / magnitude;
      let niceResidual;
      if (residual <= 1.5) niceResidual = 1;
      else if (residual <= 3.5) niceResidual = 2;
      else if (residual <= 7.5) niceResidual = 5;
      else niceResidual = 10;
      return niceResidual * magnitude;
    }

    // ========== Graduated Axes ==========
    function createGraduatedAxes(xMin, xMax, yMin, yMax, zMin, zMax) {
      // حذف گروه قدیمی محورها
      const oldAxes = scene.getObjectByName('axesGroup');
      if (oldAxes) scene.remove(oldAxes);

      const axesGroup = new THREE.Group();
      axesGroup.name = 'axesGroup';

      const axisLength = Math.max(xMax - xMin, yMax - yMin, zMax - zMin) + 1.5;
      const axisThickness = 0.04;
      const tickLength = 0.15;
      const tickThickness = 0.02;
      const fontSize = 0.3;

      function createAxisLine(color, from, to) {
        const dir = new THREE.Vector3().subVectors(to, from);
        const length = dir.length();
        const mid = new THREE.Vector3().addVectors(from, to).multiplyScalar(0.5);
        const geo = new THREE.CylinderGeometry(axisThickness, axisThickness, length, 8);
        const mesh = new THREE.Mesh(geo, new THREE.MeshBasicMaterial({ color }));
        mesh.position.copy(mid);
        const axis = new THREE.Vector3(0, 1, 0);
        const quat = new THREE.Quaternion().setFromUnitVectors(axis, dir.normalize());
        mesh.setRotationFromQuaternion(quat);
        axesGroup.add(mesh);
      }

      function createTick(from, to, color) {
        const dir = new THREE.Vector3().subVectors(to, from);
        const length = dir.length();
        const mid = new THREE.Vector3().addVectors(from, to).multiplyScalar(0.5);
        const geo = new THREE.CylinderGeometry(tickThickness, tickThickness, length, 6);
        const mesh = new THREE.Mesh(geo, new THREE.MeshBasicMaterial({ color }));
        mesh.position.copy(mid);
        const axis = new THREE.Vector3(0, 1, 0);
        const quat = new THREE.Quaternion().setFromUnitVectors(axis, dir.normalize());
        mesh.setRotationFromQuaternion(quat);
        axesGroup.add(mesh);
      }

      function createLabel(text, position, color) {
        const canvas = document.createElement('canvas');
        canvas.width = 128;
        canvas.height = 64;
        const ctx = canvas.getContext('2d');
        ctx.fillStyle = 'transparent';
        ctx.fillRect(0, 0, canvas.width, canvas.height);
        ctx.font = 'bold 38px "Segoe UI", Tahoma, sans-serif';
        ctx.fillStyle = color;
        ctx.textAlign = 'center';
        ctx.textBaseline = 'middle';
        ctx.fillText(text, 64, 32);
        const texture = new THREE.CanvasTexture(canvas);
        texture.minFilter = THREE.LinearFilter;
        const spriteMat = new THREE.SpriteMaterial({ map: texture, depthTest: false, depthWrite: false });
        const sprite = new THREE.Sprite(spriteMat);
        sprite.position.copy(position);
        sprite.scale.set(fontSize * 2, fontSize, 1);
        axesGroup.add(sprite);
      }

      // --- محور X (قرمز) ---
      const xFrom = new THREE.Vector3(xMin - 0.3, 0, 0);
      const xTo = new THREE.Vector3(xMax + 0.3, 0, 0);
      createAxisLine(0xff4444, xFrom, xTo);

      // --- محور Y (سبز) ---
      const yFrom = new THREE.Vector3(0, -Math.max(Math.abs(zMin), Math.abs(zMax)) - 0.3, 0);
      const yTo = new THREE.Vector3(0, Math.max(Math.abs(zMin), Math.abs(zMax)) + 0.3, 0);
      createAxisLine(0x44ff44, yFrom, yTo);

      // --- محور Z (آبی) ---
      const zFrom = new THREE.Vector3(0, 0, yMin - 0.3);
      const zTo = new THREE.Vector3(0, 0, yMax + 0.3);
      createAxisLine(0x4444ff, zFrom, zTo);

      // --- تیک‌ها و اعداد محور X ---
      const xStep = niceStep(xMax - xMin, 8);
      let xTickStart = Math.ceil((xMin) / xStep) * xStep;
      for (let x = xTickStart; x <= xMax; x += xStep) {
        createTick(
          new THREE.Vector3(x, -tickLength / 2, 0),
          new THREE.Vector3(x, tickLength / 2, 0),
          0xff4444
        );
        createLabel(x.toFixed(2), new THREE.Vector3(x, -0.4, 0), '#ff8888');
      }

      // --- تیک‌ها و اعداد محور Z (در Three.js به عنوان محور عمق) ---
      const zStep = niceStep(yMax - yMin, 8);
      let zTickStart = Math.ceil(yMin / zStep) * zStep;
      for (let z = zTickStart; z <= yMax; z += zStep) {
        createTick(
          new THREE.Vector3(0, -tickLength / 2, z),
          new THREE.Vector3(0, tickLength / 2, z),
          0x4444ff

        createLabel(z.toFixed(2), new THREE.Vector3(0, -0.4, z), '#8888ff');

          new THREE.Vector3(-tickLength / 2, val, 0),
          new THREE.Vector3(tickLength / 2, val, 0),
          0x44ff44

      createLabel('Z', new THREE.Vector3(0, 0, yMax + 0.8), '#6666ff');
      createLabel('Y', new THREE.Vector3(0, Math.max(Math.abs(zMin), Math.abs(zMax)) + 0.8, 0), '#66ff66');

      scene.add(axesGroup);
    }

      scene.add(gridHelper);
    }

    // ========== Function Compiler ==========
    function compileFunction(funcStr) {
      try {
        const f = new Function('x', 'y', `return ${funcStr};`);
        const test = f(0, 0);
        if (typeof test !== 'number' || !isFinite(test)) {
          return { error: 'تابع باید یک عدد برگرداند.' };
        }
        return { func: f, error: null };
      } catch (e) {
        return { error: `خطا در تجزیه: ${e.message}` };
      }
    }

    // ========== Surface Geometry ==========
    function createSurfaceGeometry(func, xMin, xMax, yMin, yMax, segments) {
      const xRange = xMax - xMin;
      const yRange = yMax - yMin;
      const geometry = new THREE.BufferGeometry();
      const vertices = [];
      const colors = [];
      const indices = [];

      const allZ = [];
      for (let i = 0; i <= segments; i++) {
        const x = xMin + (i / segments) * xRange;
        for (let j = 0; j <= segments; j++) {
          const y = yMin + (j / segments) * yRange;
          let z;
          try { z = func(x, y); } catch (e) { z = NaN; }
          if (typeof z !== 'number' || !isFinite(z)) z = 0;
          allZ.push(z);
        }
      }

      const validZ = allZ.filter(v => isFinite(v));
      let zMin = Math.min(...validZ);
      let zMax = Math.max(...validZ);
      if (zMax - zMin < 0.001) { zMin -= 0.5; zMax += 0.5; }

      let idx = 0;
      for (let i = 0; i <= segments; i++) {
        const x = xMin + (i / segments) * xRange;
        for (let j = 0; j <= segments; j++) {
          const y = yMin + (j / segments) * yRange;
          const z = allZ[idx++];
          vertices.push(x, z, y);
          const normZ = (z - zMin) / (zMax - zMin);
          const c = Math.max(0, Math.min(1, normZ));
          let r, g, b;
          if (c < 0.5) {
            const t = c * 2;
            r = 0.1; g = t; b = 1 - t;
          } else {
            const t = (c - 0.5) * 2;
            r = t; g = 1 - t; b = 0.1;
          }
          colors.push(r, g, b);
        }
      }

      for (let i = 0; i < segments; i++) {
        for (let j = 0; j < segments; j++) {
          const a = i * (segments + 1) + j;
          const b = a + 1;
          const c = a + (segments + 1);
          const d = c + 1;
          indices.push(a, b, d);
          indices.push(a, d, c);
        }
      }

      geometry.setAttribute('position', new THREE.Float32BufferAttribute(vertices, 3));
      geometry.setAttribute('color', new THREE.Float32BufferAttribute(colors, 3));
      geometry.setIndex(indices);
      geometry.computeVertexNormals();

      return { geometry, zMin, zMax };
    }

    // ========== Update Surface ==========
    function updateSurface(funcStr) {
      const xMin = parseFloat(xMinInput.value);
      const xMax = parseFloat(xMaxInput.value);
      const yMin = parseFloat(yMinInput.value);
      const yMax = parseFloat(yMaxInput.value);
      const segments = parseInt(segmentsInput.value);

      if (isNaN(xMin) || isNaN(xMax) || isNaN(yMin) || isNaN(yMax)) {
        statusMessage.textContent = '❌ بازه‌ها باید عدد باشند.';
        statusMessage.className = 'status-message error';
        return false;
      }
      if (xMin >= xMax || yMin >= yMax) {
        statusMessage.textContent = '❌ بازه نامعتبر: xMin < xMax و yMin < yMax الزامی است.';
        statusMessage.className = 'status-message error';
        return false;
      }
      if (isNaN(segments) || segments < 3) {
        statusMessage.textContent = '❌ دقت باید حداقل ۳ باشد.';
        statusMessage.className = 'status-message error';
        return false;
      }
      if (segments > 500) {
        statusMessage.textContent = '⚠️ دقت بیش از ۵۰۰ ممکن است مرورگر را کند کند.';
        statusMessage.className = 'status-message error';
        return false;
      }

      const oldSurface = scene.getObjectByName('surfaceMesh');
      if (oldSurface) scene.remove(oldSurface);
      const oldWire = scene.getObjectByName('surfaceWireframe');
      if (oldWire) scene.remove(oldWire);

      const { func, error } = compileFunction(funcStr);
      if (error) {
        statusMessage.textContent = '❌ ' + error;
        statusMessage.className = 'status-message error';
        return false;
      }

      let result;
      try {
        result = createSurfaceGeometry(func, xMin, xMax, yMin, yMax, segments);
      } catch (e) {
        statusMessage.textContent = '❌ خطا در ساخت سطح: ' + e.message;
        statusMessage.className = 'status-message error';
        return false;
      }

      const { geometry, zMin, zMax } = result;

      const material = new THREE.MeshStandardMaterial({
        vertexColors: true,
        side: THREE.DoubleSide,
        roughness: 0.4,
        metalness: 0.1,
      });
      const surface = new THREE.Mesh(geometry, material);
      surface.name = 'surfaceMesh';
      scene.add(surface);

      const wireGeo = new THREE.EdgesGeometry(geometry);
      const wireMat = new THREE.LineBasicMaterial({ color: 0x000000, transparent: true, opacity: 0.12 });
      const wire = new THREE.LineSegments(wireGeo, wireMat);
      wire.name = 'surfaceWireframe';
      scene.add(wire);

      const maxSize = Math.max(xMax - xMin, yMax - yMin, Math.abs(zMin), Math.abs(zMax));
      createGraduatedAxes(xMin, xMax, yMin, yMax, zMin, zMax);
      createGrid(maxSize);

      statusMessage.textContent = `✅ سطح: z = ${funcStr} | بازه: [${xMin}, ${xMax}] × [${yMin}, ${yMax}] | دقت: ${segments}×${segments}`;
      statusMessage.className = 'status-message';
      return true;
    }

    // ========== Event Handlers ==========
    function handleDraw() {
      const funcStr = functionInput.value.trim();
      if (!funcStr) {
        statusMessage.textContent = '⚠️ لطفاً یک تابع وارد کنید.';
        statusMessage.className = 'status-message error';
        return;
      }
      updateSurface(funcStr);
    }

    drawButton.addEventListener('click', handleDraw);
    functionInput.addEventListener('keydown', (e) => { if (e.key === 'Enter') handleDraw(); });

    resetButton.addEventListener('click', () => {

    window.addEventListener('resize', () => {

  • به‌روزرسانی زنده: با فشردن کلید Enter یا کلیک روی دکمهٔ «رسم کن»، سطح قبلی حذف و سطح جدید جایگزین می‌شود. نیازی به رفرش صفحه نیست.
  • رنگ‌آمیزی تطبیقی: کد ابتدا تمام مقادیر z را محاسبه می‌کند تا کمینه و بیشینه را پیدا کند، سپس رنگ‌ها را بر اساس آن بازه نرمال‌سازی می‌کند. بنابراین چه تابع شما بین ۰ و ۱ نوسان کند، چه بین ۱۰۰۰- و ۱۰۰۰+، رنگ‌بندی همیشه بهینه خواهد بود.
  • مدیریت خطا: اگر تابع نامعتبر باشد یا خروجی آن عدد نباشد، پیام خطای مناسبی نمایش داده می‌شود و سطح قبلی (در صورت وجود) دست‌نخورده باقی می‌ماند.
  • دکمه‌های مثال: ۸ تابع آماده در پایین صفحه قرار دارند که با کلیک روی هر کدام، هم متن ورودی به‌روزرسانی می‌شود و هم سطح جدید رسم می‌شود.

چند تابع پیشنهادی برای امتحان کردن

این عبارات را در کادر متنی وارد کنید و نتیجه را ببینید:

  • Math.sqrt(x*y) — سطح رادیکالی
  • Math.sin(x) * Math.cos(y) — سطح موج‌دار کلاسیک
  • (x*x - y*y) / 4 — سطح زین‌اسبی (هذلولی‌گون سهمی)
  • Math.exp(-(x*x + y*y) / 4) — سطح گاوسی (زنگوله‌ای)
  • Math.sin(Math.sqrt(x*x + y*y)) — امواج دایره‌ای
  • Math.cos(Math.abs(x) + Math.abs(y)) — الگوی لوزی شکل
  • Math.sin(x) + Math.cos(y) — موج ساده
  • (Math.sin(x) * Math.sin(y)) / (x*y + 0.1) — الگوی تداخلی
  • Math.sin(x*x + y*y) / (x*x + y*y + 0.5) — امواج میرا شونده

فایل را ذخیره کنید، مرورگر را رفرش کنید و نتیجه را ببینید!
